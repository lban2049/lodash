# 安全策略

本节概述了 Lodash 的安全方法，涵盖了支持的版本、漏洞的负责任披露流程，以及向维护者报告安全问题的明确指南。了解这些策略有助于确保依赖 Lodash 的项目的完整性和安全性。

## 支持的版本

下表详细说明了本项目当前接收安全更新的版本：

| 版本 | 支持状态 |
| ------- | ------------------ |
| 4.x     | :white_check_mark: |
| 3.x     | :x:                |
| 2.x     | :x:                |
| 1.x     | :x:                |

## 负责任的披露安全策略

我们制定了负责任的披露策略，以保护用户免受在修复可用之前公开披露的安全漏洞的影响。此流程首先涉及私下分类漏洞。只有在合理的时间段后，即允许修补漏洞并为用户提供升级路径后，才会进行公开披露。

我们要求您避免任何可能危及我们的用户、项目或项目团队任何成员的恶意行为。

## 报告安全问题

安全是 Lodash 的首要任务。然而，尽管我们尽了最大努力，漏洞仍然可能存在。

如果您发现安全漏洞，请直接向 Lodash 维护者报告。您可以通过 Lodash 仓库的 [安全选项卡](https://github.com/lodash/lodash/security) 进行报告。您对负责任地披露您的发现的承诺受到高度重视和赞赏。
