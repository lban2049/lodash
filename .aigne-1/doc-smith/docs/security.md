# Security Policy

This section outlines Lodash's security approach, covering supported versions, the responsible disclosure process for vulnerabilities, and clear guidelines on how to report security issues to the maintainers. Understanding these policies helps ensure the integrity and safety of projects relying on Lodash.

## Supported Versions

The following table details the versions of this project that currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 4.x     | :white_check_mark: |
| 3.x     | :x:                |
| 2.x     | :x:                |
| 1.x     | :x:                |

## Responsible Disclosure Security Policy

A responsible disclosure policy is in place to protect users from publicly disclosed security vulnerabilities before a fix is available. This process involves triaging vulnerabilities privately first. Public disclosure only happens after a reasonable period, allowing for patching the vulnerability and providing users with an upgrade path.

We ask that you avoid any malicious actions that could put our users, the project, or any of the project's team members at risk.

## Reporting a Security Issue

Security is a top priority for Lodash. However, despite our best efforts, vulnerabilities can still exist.

If you discover a security vulnerability, please report it directly to the Lodash maintainers. You can do this through the [Security tab](https://github.com/lodash/lodash/security) of the Lodash repository. Your commitment to responsibly disclosing your findings is highly valued and appreciated.
