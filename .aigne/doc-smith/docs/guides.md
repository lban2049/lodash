# Guides

This section contains a series of technical guides designed to help developers gain a deeper understanding of advanced use cases for Lodash. These guides cover topics such as performance optimization and selecting library build versions to ensure you can use Lodash most efficiently in your projects.

## Build Differences

Lodash offers various build versions to accommodate different use cases and environments, such as browsers, Node.js, and integration with bundlers like Webpack or Rollup. Selecting the right build version is crucial for optimizing your application's bundle size and loading performance.

This guide details the differences between various versions, including the core build, full build, and ES modules. It also provides instructions for creating custom builds, allowing you to bundle only the functionalities actually used in your project.

For more information, see the [Build Differences guide](./guides-build-differences.md).

## Performance

Performance is one of the core design considerations of Lodash. To help developers write high-performance code, we offer a comprehensive performance guide. This guide provides performance benchmark data for various functions based on [Benchmark.js](https://benchmarkjs.com/) and shares practical techniques for leveraging the library's internal optimizations. With this information, you can better understand the performance of different Lodash functions when processing large datasets, enabling you to make more informed technical decisions.

For detailed benchmarks and optimization tips, visit the [Performance guide](./guides-performance.md).
