# 安全

Lodash 的安全是重中之重。本文档概述了我们的安全策略，详细说明了哪些版本支持安全更新，并提供了如何报告漏洞的说明。

## 支持的版本

下表描述了项目当前正在接收安全更新的版本。

| 版本 | 是否支持          |
| ------- | ------------------ |
| 4.x     | :white_check_mark: |
| 3.x     | :x:                |
| 2.x     | :x:                |
| 1.x     | :x:                |

## 负责任的披露政策

负责任的披露政策有助于保护项目用户，避免他们在没有修复方案的情况下受到公开披露的安全漏洞的影响。该政策采用一个流程，即首先以非公开方式对漏洞进行分类，只有在经过一段合理的时间，允许修复漏洞并为用户提供升级路径后，才会公开发布。

我们恳请您不要采取恶意行为，以免我们的用户、项目或任何项目团队成员面临风险。

## 报告安全问题

如果您发现安全漏洞，请通过 Lodash 仓库的 [Security 选项卡](https://github.com/lodash/lodash/security)直接向 Lodash 维护者报告该问题。

我们真诚地感谢您为负责任地披露您的发现所做的努力，这是对社区安全的宝贵贡献。
