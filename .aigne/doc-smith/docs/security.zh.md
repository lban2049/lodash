# 安全性

我们将 Lodash 的安全性视为重中之重。本文档详细介绍了项目的安全策略、接收安全更新的版本，以及如何负责任地报告漏洞。

## 支持的版本

下表描述了本项目当前支持安全更新的版本：

| 版本 | 支持          |
| ------- | ------------------ |
| 4.x     | :white_check_mark: |
| 3.x     | :x:                |
| 2.x     | :x:                |
| 1.x     | :x:                |

## 负责任的披露政策

负责任的披露政策有助于保护项目用户，使其免受在没有修复程序的情况下公开披露的安全漏洞的影响。该政策采用一个流程，即漏洞首先进行私下分类，只有在经过一段合理的时间后才予以公开披露，这段时间用于修补漏洞并为用户提供升级路径。

我们恳请您不要采取任何恶意行为，以免我们的用户、项目或任何项目团队成员面临风险。

## 报告漏洞

如果您发现安全漏洞，请通过 Lodash 仓库的 [Security 标签页](https://github.com/lodash/lodash/security)直接向 Lodash 维护者报告该安全问题。

我们真诚地感谢您为负责任地披露您的发现所做的努力。
