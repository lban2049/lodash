# 安全性

本节详细说明了项目的安全策略、接收安全更新的版本以及负责任地披露漏洞的流程。

## 支持的版本

下表列出了当前受安全更新支持的 Lodash 版本。建议始终使用受支持的版本，以确保您的应用程序保持安全。

| 版本 | 支持状态 |
| ------- | ------------------ |
| 4.x | :white_check_mark: |
| 3.x | :x: |
| 2.x | :x: |
| 1.x | :x: |

## 负责任的披露政策

负责任的披露政策有助于保护项目用户，避免其受到在没有修复方案的情况下被公开披露的安全漏洞的影响。该政策采用的流程是：首先对漏洞进行私下分类处理，只有在经过一段合理的时间后才公开发布。这段时间用于修补漏洞，并为用户提供升级路径。

我们恳请您不要采取任何可能危及我们的用户、项目或任何项目团队成员的恶意行为。

## 报告漏洞

Lodash 的安全性是我们的首要任务。然而，无论在安全方面投入多少精力，漏洞仍可能存在。

如果您发现安全漏洞，请通过 Lodash 代码库的 [Security 选项卡](https://github.com/lodash/lodash/security) 直接向 Lodash 维护者报告。

我们由衷感谢您为负责任地披露您的发现所做的努力，这是对社区安全性的宝贵贡献。
