# 安全性

Lodash 团队将项目的安全性视为重中之重。本文档详细介绍了我们的安全策略、接收安全更新的版本，以及负责任地报告您可能发现的任何漏洞的流程。

## 支持的版本

下表说明了当前哪些 Lodash 版本支持安全更新：

| Version | Supported          |
| ------- | ------------------ |
| 4.x     | :white_check_mark: |
| 3.x     | :x:                |
| 2.x     | :x:                |
| 1.x     | :x:                |

## 负责任的披露政策

负责任的披露政策有助于保护用户，使其免受已公开但尚无修复方案的安全漏洞的影响。该政策采用的流程是：首先对漏洞进行内部评估，并在一段合理的时间（足以修复漏洞并为用户提供升级路径）之后，才进行公开披露。

我们恳请您不要采取任何可能危及我们的用户、项目或任何项目团队成员的恶意行为。

## 报告漏洞

如果您发现安全漏洞，请通过 Lodash 仓库的 [Security tab](https://github.com/lodash/lodash/security) 直接向 Lodash 维护人员报告此问题。

我们衷心感谢您为负责任地披露您的发现所做的努力，这是对社区安全性的宝贵贡献。
