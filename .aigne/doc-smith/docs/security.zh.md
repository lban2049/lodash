# 安全策略

我们将 Lodash 的安全性视为重中之重。但无论我们在安全方面投入多少精力，仍然可能存在漏洞。本页面详细说明了我们的安全策略、受支持的版本以及如何报告安全问题。

## 支持的版本

下表描述了当前提供安全更新支持的项目版本：

| 版本 | 支持状态 |
| --- | --- |
| 4.x | :white_check_mark: |
| 3.x | :x: |
| 2.x | :x: |
| 1.x | :x: |

## 负责任的披露政策

负责任的披露政策有助于保护项目用户免受在没有修复方案的情况下公开披露的安全漏洞的影响。我们采用的流程是，首先以非公开方式对漏洞进行分类处理，并在经过一段合理的时间（允许修复漏洞并为用户提供升级路径）后才公开发布。

我们恳请您不要采取任何可能危及我们的用户、项目或任何项目团队成员的恶意行为。

## 报告安全问题

如果您发现安全漏洞，请通过 Lodash 仓库的 [Security 选项卡](https://github.com/lodash/lodash/security) 直接向 Lodash 维护者报告。

我们衷心感谢您为负责任地披露您的发现所做的努力。
