# API 参考

欢迎来到 Lodash API 参考。本节为所有 Lodash 方法提供了详尽且可搜索的参考文档。为了便于快速查找，所有方法均已按其操作的数据类型进行分类。每个类别都包含详细的函数签名、参数说明、返回值和可直接使用的代码示例。

如果您对 Lodash 的函数式编程范式感兴趣，请查阅我们的[函数式编程指南](./fp-guide.md)。
