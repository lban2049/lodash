# Contributing & Community

Lodash welcomes community involvement and contributions. This section provides the essential resources for getting involved with the project, whether through code contributions, bug reports, or community discussions.

## How to Contribute

Before creating issues or pull requests, please consult the following resources to ensure a smooth and effective contribution process.

<x-cards data-columns="2">
  <x-card data-title="Contribution Guidelines" data-icon="lucide:file-code" data-href="https://github.com/lodash/lodash/blob/master/.github/CONTRIBUTING.md">
    The official guide covers coding standards, commit message formats, and the development process. All code contributions should follow these guidelines.
  </x-card>
  <x-card data-title="Code of Conduct" data-icon="lucide:shield" data-href="https://js.foundation/conduct/">
    All participants in the Lodash community are expected to adhere to the JS Foundation Code of Conduct to foster an open and welcoming environment.
  </x-card>
</x-cards>
