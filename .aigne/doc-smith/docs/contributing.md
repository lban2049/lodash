# Contributing & Community

Lodash is an open-source project that thrives on community participation. We welcome contributions of all kinds, from bug reports and documentation improvements to new feature suggestions and pull requests.

## Contribution Guidelines

Before contributing, please review the official **[Contributing Guide](https://github.com/lodash/lodash/blob/master/.github/CONTRIBUTING.md)** on GitHub. This document provides detailed instructions on the development process, coding standards, and how to submit pull requests. Adhering to these guidelines helps maintain the quality and consistency of the project.

Lodash is released under the [MIT license](https://raw.githubusercontent.com/lodash/lodash/4.17.21/LICENSE).

## Code of Conduct

To ensure a welcoming and inclusive environment for everyone, all participants are expected to adhere to the **[JS Foundation Code of Conduct](https://js.foundation/conduct/)**. Please read it to understand the community standards.

## Community Channels

Connect with the Lodash community and maintainers through the following channels:

*   **[Chat on Gitter](https://gitter.im/lodash/lodash)**: For real-time discussions with other users and contributors.
*   **[Follow on Twitter](https://twitter.com/bestiejs)**: For project announcements and updates.
*   **[Explore the Wiki](https://github.com/lodash/lodash/wiki)**: Find the project changelog, roadmap, and other related documentation.
*   **[Official Site & Docs](https://lodash.com/)**: The primary resource for official documentation and examples.
