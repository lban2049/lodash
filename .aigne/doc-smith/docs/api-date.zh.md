# Date

本节提供了处理 Date 对象的 Lodash 函数的参考。这些实用工具可帮助您在应用程序中管理与时间相关的数据。如需了解其他杂项实用工具，您也可以参考 [Util](./api-util.md) 部分。

---

## now()

获取自 Unix 纪元（1970 年 1 月 1 日 00:00:00 UTC）以来所经过的毫秒数时间戳。

### 详细信息

| 详细信息 | 描述 |
| :---------- | :------------------------------------------- |
| **版本** | 2.4.0 |
| **返回值** | `(number)`: 返回当前时间戳。 |

### 示例

本示例使用 `_.defer` 来演示如何使用 `_.now()` 测量时间间隔。

```javascript
_.defer(function(stamp) {
  console.log(_.now() - stamp);
}, _.now());
// => 输出延迟调用所经过的毫秒数。
```
