# 指南

本部分包含一系列技术指南，旨在帮助开发者深入了解 Lodash 的高级用例。这些指南涵盖了性能优化和库构建版本的选择等主题，以确保您在项目中能够最高效地使用 Lodash。

## 构建差异

Lodash 提供了多种构建版本，以适应不同的使用场景和环境，例如浏览器、Node.js 以及与 Webpack 或 Rollup 等打包工具的集成。选择合适的构建版本对于优化应用程序的包大小和加载性能至关重要。

本指南详细解释了核心构建、完整构建以及 ES 模块等不同版本之间的区别，并提供了创建自定义构建的指导，帮助您只打包项目中实际使用到的功能。

要了解更多信息，请参阅[构建差异指南](./guides-build-differences.md)。

## 性能

性能是 Lodash 的核心设计考量之一。为了帮助开发者编写出高性能的代码，我们提供了详尽的性能指南。该指南基于 [Benchmark.js](https://benchmarkjs.com/) 提供了各个函数的性能基准测试数据，并分享了利用库内部优化的实践技巧。通过这些内容，您可以更好地理解不同 Lodash 函数在处理大规模数据时的性能表现，从而做出更明智的技术选型。

要获取详细的基准测试和优化技巧，请访问[性能指南](./guides-performance.md)。
