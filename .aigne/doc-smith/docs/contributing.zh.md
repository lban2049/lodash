# 贡献与社区

Lodash 社区欢迎所有形式的贡献，无论是报告问题、提出新功能建议，还是直接贡献代码。我们相信，开放的协作是项目保持活力和不断进步的关键。本节将为你提供参与 Lodash 项目所需的所有信息。

## 加入社区讨论

你可以通过以下渠道与其他 Lodash 用户和开发者交流：

- **Gitter 聊天室**: [gitter.im/lodash/lodash](https://gitter.im/lodash/lodash) - 获取帮助、讨论功能或与其他社区成员进行实时交流的最佳场所。
- **Twitter**: [@bestiejs](https://twitter.com/bestiejs) - 关注我们的官方 Twitter 账号，获取最新的项目动态和公告。

## 如何贡献

我们非常感谢你愿意花时间为 Lodash 做出贡献。为了确保协作过程顺利高效，请遵循以下指南。

### 行为准则 (Code of Conduct)

在参与社区和贡献代码之前，请务必阅读并遵守我们的 [行为准则](https://js.foundation/conduct/)。我们致力于维护一个友好、互相尊重和富有建设性的社区环境。

### 贡献指南 (Contributing Guide)

所有代码相关的贡献都应遵循官方的 [贡献指南](https://github.com/lodash/lodash/blob/master/.github/CONTRIBUTING.md)。该文档详细说明了如何设置开发环境、运行测试、提交问题 (Issues) 和发起拉取请求 (Pull Requests)。请在发起 Pull Request 前仔细阅读，以确保你的贡献符合项目规范。

### 项目 Wiki

项目的 [Wiki](https://github.com/lodash/lodash/wiki) 包含了更多关于项目规划和历史的信息，例如更新日志 (Changelog) 和发展路线图 (Roadmap)。在提出新功能建议前，查阅 Wiki 可能会为你提供有价值的背景信息。
