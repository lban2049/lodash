# 贡献与社区

Lodash 项目的成长离不开社区的支持。我们欢迎各种形式的贡献，无论是报告问题、建议新功能，还是直接提交代码。本节将为你提供参与 Lodash 项目所需的核心信息和链接。

## 加入社区讨论

你可以通过以下渠道与其他 Lodash 用户和开发者交流，获取帮助或分享想法：

- **Gitter 聊天室**: [gitter.im/lodash/lodash](https://gitter.im/lodash/lodash) - 与社区成员进行实时交流、讨论功能或寻求帮助的最佳场所。
- **Twitter**: [@bestiejs](https://twitter.com/bestiejs) - 关注官方 Twitter 账号，获取最新的项目动态和公告。

## 如何贡献

我们非常感谢你为 Lodash 付出时间。为确保协作过程高效、顺畅，请在开始前查阅以下关键文档。
