# 贡献与社区

Lodash 是一个依靠社区贡献而蓬勃发展的开源项目。无论是报告错误、建议功能还是编写代码，您的参与都将受到高度重视。本文档提供了您参与其中所需的资源。

## 如何贡献

我们 GitHub 上的 `CONTRIBUTING.md` 文件是贡献者的主要资源。其中包含有关我们的开发流程、编码规范以及如何提交拉取请求的详细信息。

<x-card data-title="贡献指南" data-icon="lucide:file-text" data-href="https://github.com/lodash/lodash/blob/master/.github/CONTRIBUTING.md" data-cta="阅读指南">
有关如何贡献的详细信息，包括我们的代码规范、拉取请求流程以及如何设置开发环境，请查阅我们在 GitHub 上的官方贡献指南。
</x-card>
