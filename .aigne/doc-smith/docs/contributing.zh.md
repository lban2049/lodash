# 贡献与社区

Lodash 是一个开源项目，其发展离不开活跃社区的贡献。我们欢迎并感谢所有形式的贡献，包括报告错误、提出功能建议、改进代码和完善文档。

## 如何贡献

贡献者的主要参考资源是 GitHub 上的官方 **[贡献指南](https://github.com/lodash/lodash/blob/master/.github/CONTRIBUTING.md)**。该指南详细介绍了开发流程，包括如何设置环境、提交问题、创建拉取请求以及遵守项目的编码规范。

在开始之前，我们还建议您查阅项目的 **[Wiki](https://github.com/lodash/lodash/wiki)**，其中包含官方的更新日志、路线图和其他重要的项目信息。这将帮助您了解该库当前的重点和发展方向。

## 行为准则

为了营造一个积极、尊重和包容的环境，Lodash 项目采纳了 JS 基金会的 **[行为准则](https://js.foundation/conduct/)**。我们希望社区的所有参与者——包括贡献者、维护者和用户——在所有与项目相关的互动中都能遵守这些准则。

## 加入讨论

通过我们的社区渠道与其他 Lodash 用户和贡献者建立联系。无论您是需要帮助、希望分享想法，还是只想与社区交流，这些平台都是最佳选择。
